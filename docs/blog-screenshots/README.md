## 직접 찍어야 하는 것 — ③ 슬랙 계약 알림

`caselab_slack.png` (2880×약 700 정도면 충분)

CaseLab이 계약 체결을 감지해서 담당 매니저를 태그해 보낸 **실제 슬랙 메시지**를 찍어주세요.
글에서 요구하는 건 "담당 매니저 태그된 실제 알림 메시지 (고객명·금액은 가려서)"입니다.

- 메시지 1~2건이 보이게, 슬랙 창을 **좁게(600~800px)** 만들어서 찍으면 블로그에서 읽기 좋습니다
- **고객사명과 계약금액은 가려주세요** (다른 이미지들과 톤을 맞추려면 블러가 좋습니다)
- 담당 매니저 멘션은 남겨두는 게 "태그해서 알린다"는 포인트가 살아납니다
- 파일명을 `caselab_slack.png`로 해서 이 폴더에 넣으면 나머지와 그대로 이어집니다

## 마스킹 기준

공개 저장소에 올라가므로 아래만 블러 처리했습니다.

- **가림**: 고객사명, 검수담당·매니저 이름, 개발사(파트너) 계정명
- **안 가림**: 프로젝트명(위시켓에 공개된 공고 제목), 금액, 통계, AI 요약·검수 팁 본문, 로그인한 본인 계정

가리는 범위를 바꾸고 싶으면(예: 매니저 이름은 노출, 금액도 가림) 다시 캡처하면 됩니다.

## 알아둘 점

- `caselab_timeline.png`은 한 장에 담기 위해 프로젝트 상세에서 **유사 프로젝트 / 매니저 노트 / 미팅 이슈 로그 / 개발사 Q&A / 완료 리뷰 섹션을 숨기고** 찍었습니다. 가공 없는 원본은 `caselab_detail_full.png`입니다.
- ⑤와 ⑥은 서로 다른 의뢰문으로 돌린 결과입니다(⑤ 반려동물 매칭 앱 / ⑥ 숏폼 영상 자동 생성). 같은 의뢰문으로 맞추고 싶으면 말해주세요.
- 리포트의 KPI 카드에서 "600만원", "1,464만원"이 두 줄로 접히는 건 실제 앱 렌더링 그대로입니다(컨테이너 max-width 때문). 고치려면 앱 CSS 수정이 필요합니다.
