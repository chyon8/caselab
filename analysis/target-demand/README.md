# 공고 수요 기반 타깃 분석 — 재착수 입력

이 폴더에는 다음 분석을 위해 필요한 **비식별 입력 원장만** 남긴다. 이전의 넓은 수요 태그,
성과표, AI 라벨, 후보 결론은 사용자의 목표와 맞지 않아 제거했다.

정확한 목표·실패 원인·다음 세션의 시작 순서는 반드시 [NEXT_SESSION.md](./NEXT_SESSION.md)를
먼저 읽는다.

## 남긴 파일

| 파일 | 용도 |
|---|---|
| `corpus.json` | 가명 ID, 제출 월, 원문 출처, 개인정보 제거 공고 본문. 성과 정보 없음. |
| `outcomes.json` | 같은 가명 ID의 제출·모집·계약 관찰용 성과 원장. 원문 분류 모델 입력에 사용 금지. |
| `data-manifest.json` | 입력 추출 시점·월별 건수·해시. |
| `audit.json` | 전체 4,319건·누적 모집 1,932건 원천 대조 기록. |
| `NEXT_SESSION.md` | 새 분석의 질문·분석 단위·재착수 규칙. |

## 고정 범위

- 2026년 1~8월 제출 도급 프로젝트 4,319건
- 모집: 제출 후 14일을 주 지표로 사용
- 계약: 제출 후 90일, 모집 후 90일을 별도로 사용
- 실제 프로젝트 번호 대응표는 Git에 두지 않는다.

새 분석을 시작할 때는 이 입력을 덮어쓰지 않고, 새 분류·집계 산출물을 별도 작업 단위로 만든다.
