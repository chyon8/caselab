# 제출 원문 업종·서비스 판정

제출 전 원문 859건(`../review/text-samples.json`)을 읽고 업종군·시스템 유형을 판정한다. 분류 체계는 타깃 수요 분석 v2의 업종군 33 · 시스템 유형 38을 그대로 쓴다(`.private/target-demand/v2/rollup-*.tsv`).

- 판정 시 모집 결과(`../review/analysis-targets.json`)는 보지 않는다.
- `labels/bNN.tsv`: `anon_id<TAB>업종군<TAB>시스템 유형<TAB>메모`
- 업종군: 발주처 사업 분야, 또는 서비스가 겨냥하는 업종이 원문에서 확인될 때만 적는다. 추정이 필요하면 `미상`.
- 시스템 유형: 만들려는 것. 폼 예시 문구만 남은 빈 양식은 `미상`. 개발이 아닌 디자인·자문·단순작업은 `기타(비개발)`.
